# GoodweWifiFirmware
# As requested here: https://github.com/mletenay/home-assistant-goodwe-inverter/issues/174
# 
# How to:
# 1. Download the above firmware file to your client (phone, tablet, pc)
# 2. Connect your client to your solar WiFi network, usually named "Solar-WiFi" and some numbers from the serial number
# 3. Enter your WiFi password, in case you didn't change it the default is 12345678
# 4. Open a web browser and go to http://10.10.100.253 (or just 10.10.10.253)
# 5. Log in, the default username / password is admin / admin (and I think there's no way to change this)
# 6. Upload the firmware file from 1 under Management, Upgrade Software
